# 渐变带 · 从零开始（快速上手）

> 📦 **已归档**（2026-09 文档三合一）：上手流程已并入根目录 README.md。

> 一句话：**正文 AI 讲故事，脚本自动算账**。你只要：装好 → 开局 → 把状态栏/开局页导入正则 → 开聊。

---

## 第 0 步：装什么

两种装法，二选一：
- **扩展版**：manifest 安装（GitHub main 分支，自动更新）——装完刷新酒馆页。
- **脚本版**：酒馆助手导入 `releases/酒馆助手脚本-开局.json`（tag 版，从 jsDelivr 拉取，自动更新）。

两个都要求：装好 **TavernHelper（酒馆助手）**。

## 第 1 步：导入两个正则（每次更新 HTML 都要重做一次）

酒馆「正则」页新建两条（替换 `<StatusPlaceHolderImpl/>` / `<渐变带开局/>`）：

> 懒人法：正则页支持直接导入 JSON——导入 `json/regex-开局.json` 与 `json/regex-状态栏.json`
> 即可（replaceString 已对齐当前版本 dist，更新版本后同样要重新导入）。

| 查找 | 替换为 | 干什么 |
|---|---|---|
| `<渐变带开局/>` | `dist/开局界面.html` 全文 | 是**开局面板**的入口 |
| `<StatusPlaceHolderImpl/>` | `dist/状态栏面板-双桌.html` 全文 | 是**状态栏/双桌工作台** |

> 更新版本后：重新复制新 dist 内容覆盖这两条正则即可。

## 第 2 步：开局（一次）

1. 向 AI 发一句带 `开局` 的引导 **并让 AI 回复里带上 `<渐变带开局/>`**（或在「渐变带」页点「注入开局面板到最新楼」），正文回复里出现开局面板。
2. 在面板里选：
   - **01 身份**：姓名（默认小王）、性别
   - **01+ 女主**：默认**不要**；「要女主」才会建陆安追踪表
   - **02 难度/预设**：普通 100 / 困难 65 / 爽文 220 点（或一键预设：优等生/拾荒者/战略级）
   - **03 亲和**：18 分支点选，主/次按点数计价（每多开分支，冲突与塑形难度剧增）
   - **04 四维**：能量上限/精神上限/持续输出/瞬时输出，E→S 档位计价
   - **05 初始回路**：按亲和自动授予基础固定回路（不用选）
   - **06 开场白**：① 作者预设（需开女主）② AI 自动生成（请求含玩家信息，复制到聊天自己发）
3. 点「**确认档案并固化神经回路**」→ 存档写入 → 第 0 楼生成开场白 → 开聊。

> 不要女主时：自动关闭开局框架的「启用标准表格（自动填表）」（渐变带只用数据AI/法术AI）。

## 第 3 步：日常玩

每一条 AI 回复后，扩展自动跑一遍回合：
1. **状态栏**：最新楼末尾自动替换出双桌工作台（回路配置桌/角色桌/自由施法桌）
2. **数据AI** 读正文 → 报状态变更包（扣费/恢复/补给/新法术等）
3. **脚本结算**：挂账单、计次数、按时间自动恢复（能量按上限连续充能、精神 Mmax/900）、重算过载
4. **快照** 同步到最新楼 → 状态栏显示最新数值

你可以在**回路配置桌**上动手：
- **装槽**：牌库点牌上桌 → 拖进固定槽（仅固化）/自由槽；固定槽只进固化回路
- **手操**：开手操开关 → 圈选槽位「使用」→ 回合末统一扣费
- **送审**：待送审牌拖进「法案审核台」→ 点送审（法术AI 填参数）→ 通过/驳回/超时均回牌库
- **补给**：晶体/导液是库存（右下能量/精神补给匣，滑杆按比例注入）；喷雾/贴片是卡片，点用
- **删除**：拖进「销毁台」→ 确认后永久删除
- **更新过载**：点「⟳ 手动更新过载」重算全回路过载率/风险

## 第 4 步：设置（可跳过）

「渐变带」面板总览/设置/提示词/工具 几个 tab：
- **设置**：开关（自动结算、状态栏标记）、频率（数据AI 每 N 条一次）、API（数据AI/法术AI 各自的 API）
- **提示词**：数据AI/法术AI 段级编辑；觉得不对就点「恢复默认」
- **工具**：手动结算、手动同步快照、清存档、导入正则说明

## 常见问题

| 现象 | 解决 |
|---|---|
| 桌 2/3 不显示 / 旧界面 | 重新导入 `状态栏面板-双桌.html` 正则并刷新 |
| 提示词还是旧的 | 渐变带·提示词页 → 数据AI/法术AI 各点「恢复默认」 |
| 自动填表没动静 | 女主未开启时标准表格自动填表是关的（正常）；开女主可到覆盖面板重开 |
| 数值不懂 | 正文AI 只看到「锚点级」描述（重拳/步枪弹/公斤TNT…），精算全在脚本 |
