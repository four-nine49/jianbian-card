## 2. 改动明细（按文件）

### 2.1 新文件 `src/ui/pages/api.ts` ★核心

- `renderApiPage(el)`：三段从上到下——
  1. **填表 API（开局框架·标准表格）**：整段从 `ui/pages/settings.ts` 平移，DOM id 原样保留 `of-a-mode / of-a-stream / of-a-custom / of-a-proxy / of-a-url / of-a-key / of-a-model / of-a-temp / of-a-max / of-a-src / of-a-save`（含流式开关与「接口类型」字段）。
  2. **数据AI（渐变带）** / 3. **法术AI（渐变带）**：由页内 `gbSection(which, cfg, idp, desc)` 模板函数生成，id 前缀 `of-api-data-*` / `of-api-spell-*`（mode/proxy/url/key/model/temp/max/save）。比原来 gradband 页的 gbfc-seg 简易 UI 更完整，风格与设置页 of- 控件一致。
- 保存逻辑：填表走 `saveSettingsPatch({ fillApi: {...} })`（core/settings）；渐变带两个走 `loadGbSettings()` → 改 `s.api[which]` → `saveGbSettings(s)`（gradband/core/settings），保存时 **`{ ...s.api[which], mode, ... }` 展开保留未知字段**（如 source），别改成整对象替换丢字段。
- 兜底值：显示 `cfg.temperature ?? 0.8`、`cfg.max_tokens ?? 5000`；保存 `|| 0.8` / `|| 5000`。
- 渐变带 ApiConfig（gradband/core/settings.ts 的 TS interface，非 zod）没有改动——默认值只体现在 UI 兜底；tavern 模式下 temperature/max_tokens 仍不下发（`customApiOf` 只在 custom 模式带数值）。

### 2.2 `src/ui/app.ts`

- import `renderApiPage`；PAGES 数组加了 **两条** `{ name: 'api', label: 'API', order: 35, render: renderApiPage }`，一条 `modes: ['presets']`、一条 `modes: ['gradband']`（排在 sheetconf=30 与 settings=40 之间）。

### 2.3 `src/ui/pages/settings.ts`

- 删掉整个「填表 API」HTML 段及其 JS 绑定（`#of-a-*` 全套），文件头注释注明已移至 API 页。
- 保留：界面（悬浮按钮）/ 引导对话 API / 全局默认 / 调度。**引导对话 API 是刻意留下的**——用户说的是「3 个 API」，即填表+数据AI+法术AI；引导对话属于开局引导（且对话页只在 presets 模式），不算在内。用户若后续要求挪走，是 trivial 改动。
- 引导对话保存兜底与提示文案同步 0.8 / 5000（`|| 0.7→|| 0.8`、`|| 2048→|| 5000`）。

### 2.4 `src/ui/pages/gradband.ts`

- 设置 tab 删掉「API（三态）」整段（数据AI/法术AI 卡片），原处留一行提示 `数据AI / 法术AI 的 API 配置已移至侧栏「API」页`。该 tab 现在只剩 开关 + 结算频率。
- 删掉 `gbfc-seg[data-apimode]` / `input[data-api]` 两组事件绑定和 `type ApiConfig` import（`loadSettings/saveSettings/Settings` 仍被 开关/频率 用，别误删）。`esc()` 仍被总览/工具 tab 使用。

### 2.5 `src/store/types.ts`

- `FillApiConfig`：`temperature: z.number().default(0.8)`、`maxTokens: ...default(5000)`（原 0.6 / 2048）。
- `DialogueApiConfig` extends FillApiConfig → **自动继承新默认**，未单独改。
- ⚠️ **zod 默认不迁移旧值**：已保存过设置的用户，其 extensionSettings 里的 0.6/2048 具体值会原样保留——这是「默认」的正确语义，别加迁移代码强改用户已存值。

### 2.6 `src/ui/styles.ts`

- `.of-modepicker`：`top:6px; right:18px`（内容区右上）→ **`top:8px; left:10px`**（窗口左上角、侧栏上方）。仍是 `.of-panel{position:relative}` 的 absolute 子元素，不会盖标题栏 ✕（左上角在 nav 区域上方，不与标题栏重叠）。
- `.of-nav`：`padding:8px 0` → **`padding:36px 0 8px`**，给左上角的模式按钮留出空间（modepicker z-index:5，约占 top 8~30px）。
- 手机端（≤640px media query）`.of-modepicker{position:static;...}` 和 `.of-nav{padding:4px}` 不受影响，未改。
