# 渐变带 · 自由回路 — SillyTavern 扩展（开局框架）

> 一句话：**正文 AI 讲故事，脚本自动算账。** 开局点一点面板就能玩，数值全程不用手抄。

---

## 这是什么

给 SillyTavern（酒馆）写的一个扩展插件，核心做三件事：

- **可视化开局**：不用手动填一堆设定，在面板上点选即可，数据自动写入存档
- **自动记账**：每条 AI 回复后，脚本自动结算数值（扣费/恢复/补给/状态变更），AI 忘了数值也不怕
- **状态栏面板**：最新楼自动渲染出可操作的工作台，玩家直接在上面装槽、手操、送审、补给

面板顶部有模式切换器：

| 模式 | 玩什么 |
|---|---|
| **剑与汽水** | 角色卡专用开局：四条线向导式点几下，自动写入 9~10 张表的初始数据 |
| **渐变带 · 自由回路** | 本扩展的重头戏：科幻魔法跑团，回路/施法/过载系统，详见下文 |

## 运行原理（为什么数字不会乱）

页面上有三个东西在协作，靠**酒馆聊天变量**通信：

```
① 扩展后台（常驻，含计算引擎）← 你只看到它的悬浮球 🎬
     │  监听每条 AI 回复：调 数据AI 把正文翻译成"状态变更包"
     │  → 计算引擎按公式结算 → 结果写回聊天变量
② 开局面板（注入楼层的 HTML）  ← 建档用，玩起来后不再需要
③ 状态栏工作台（注入楼层的 HTML）← 读变量渲染双桌；你的每次操作当场写回变量、调用引擎
```

**铁律：数字只被脚本改。** 正文 AI 只看到"锚点级"描述（重拳/步枪弹/公斤TNT…），
精算全部在本地引擎 `CircuitEngine` 里完成，所以正文怎么写，数值都不会飘。

## 安装（二选一，装一个就行）

前提：先装好 **TavernHelper（酒馆助手）** 扩展并启用。

| 形态 | 方法 | 更新 |
|---|---|---|
| **扩展版** | 扩展管理器安装（GitHub 仓库地址），装完刷新酒馆 | 酒馆启动时自动拉取 |
| **脚本版** | 酒馆助手导入 `releases/酒馆助手脚本-开局.json` 并启用 | 自动（从 CDN 拉最新 tag） |

⚠️ 两种**不要同时启用**，会互相拦截提示。

## 渐变带 · 自由回路 上手四步

**第 0 步 · 导入两条正则**（每次更新 HTML 都要重做一次）

酒馆「正则」页新建两条，或直接导入 `json/` 下的现成包：

| 查找 | 替换为 | 干什么 |
|---|---|---|
| `<渐变带开局/>` | `dist/开局界面.html` 全文 | 开局面板入口（懒人法：导入 `json/regex-开局.json`） |
| `<StatusPlaceHolderImpl/>` | `dist/状态栏面板-双桌.html` 全文 | 状态栏/双桌工作台（懒人法：导入 `json/regex-状态栏.json`） |

**第 1 步 · 开局**：向 AI 发一句带 `开局` 的引导并让它回复里带上 `<渐变带开局/>`
（或在「渐变带」页点「注入开局面板到最新楼」），正文里出现开局面板，点选：

1. **01 身份**：姓名（默认小王）、性别
2. **01+ 女主**：默认不要；要女主才会建陆安追踪表
3. **02 难度/预设**：普通 100 / 困难 65 / 爽文 220 点（或一键预设：优等生/拾荒者/战略级）
4. **03 亲和**：18 分支点选，主/次按点数计价
5. **04 四维**：能量上限/精神上限/持续输出/瞬时输出（E→S 档位计价）
6. **05 初始回路**：按亲和自动授予，不用选；**06 开场白**：作者预设（需女主）或 AI 生成

点「**确认档案并固化神经回路**」→ 存档写入 → 第 0 楼生成开场白 → 开聊。

**第 2 步 · 日常玩**：每条 AI 回复后自动跑一遍回合（数据AI→结算→快照→状态栏刷新）。
你可以在状态栏的**回路配置桌**上动手：

- **装槽**：牌库点牌上桌 → 拖进固定槽/自由槽
- **手操**：开手操开关 → 圈选槽位「使用」→ 回合末统一扣费
- **送审**：自创回路拖进「法案审核台」→ 法术AI 审核 → 通过/驳回/超时
- **补给**：晶体/导液是库存（滑杆按比例注入）；喷雾/贴片是卡片，点用
- **删除**：拖进「销毁台」→ 确认后永久删除
- **更新过载**：点「⟳ 手动更新过载」重算全回路过载率/风险

**第 3 步 · 设置（可跳过）**：「渐变带」面板里可调自动结算开关、数据AI 频率、
提示词（数据AI/法术AI 段级编辑，可恢复默认）；填表/数据AI/法术AI 三处 API 集中在侧栏「API」页。

## 版本更新

- **逻辑部分自动更新**：扩展版随酒馆启动拉取；脚本版每次加载从 CDN 取最新 tag
- **HTML 面板要手动**：重新复制新 `dist/` 的两个 HTML 覆盖那两条正则（或重导 `json/` 包）
- 历史版本更新日志：看 git tag / `归档/README-旧版含更新日志.md`

## 常见问题

| 现象 | 解决 |
|---|---|
| 桌 2/3 不显示 / 旧界面 | 重新导入 `json/regex-状态栏.json`（或复制新双桌 HTML）并刷新 |
| 提示词还是旧的 | 渐变带·提示词页 → 数据AI/法术AI 各点「恢复默认」 |
| 自动填表没动静 | 女主未开启时标准表格自动填表是关的（正常）；开女主可到覆盖面板重开 |
| 数值不懂 | 正文AI 只看到「锚点级」描述，精算全在脚本，以状态栏显示为准 |

## 文档地图

本项目只有 3 份现行文档：

1. **README.md**（本文件）——给人看：是什么、怎么装、怎么玩
2. **AGENTS.md**——给 AI 看的总介绍：架构、目录、数据流、修改规矩
3. **docs/具体介绍.md**——给 AI 看的技术细节：引擎公式、状态栏契约、世界书参考、提示词契约

旧文档与历史会话快照都在 `归档/`（仅供追溯，不代表现状）。
